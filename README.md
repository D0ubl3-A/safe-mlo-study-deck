# SAFE MLO Study Deck

Static study deck for SAFE MLO exam prep, including timed call mode, scoring, missed-card review, and portable continue codes.

Live app: https://d0ubl3-a.github.io/safe-mlo-study-deck/

## Accuracy

The federal content was reviewed on July 10, 2026 against the current NMLS test outline, CFPB Regulations B/X/Z, the SAFE Act, FCRA/Regulation V, the Homeowners Protection Act, and official 2026 HOEPA/QM adjustments. Date-sensitive cards say `2026` explicitly. State requirements can be stricter or add state-specific rules.

Run the local checks after changing the deck:

```powershell
node scripts\validate-deck.js
```
